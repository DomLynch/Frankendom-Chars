# Frankendom-Chars

This repository owns character design, reconstruction, fitting and review assets only. It does not own the Frankendom game or its deployment.

Read README.md, PROJECT_STATE.md, docs/GPT-WEB-HANDOVER.md and skills/frankendom-character-pilot/SKILL.md. Preserve the original character/rig and accepted decisions. Treat characters/*/case as historical recipes and evidence: inspect their paths, credentials and post-export repair order before running them. Work in a new directory under work/; never overwrite selected inputs.

No cloud generation or paid calls belong in automatic checks. User authorization and an explicit timeout/cost bound are required for new cloud runs. Never embed credentials in files or logs. Use the current account's private output dataset, not the historical author's dataset by default.

Run every command in .quality-gate.json. Checks verify publication integrity, not artistic quality, continuous collision clearance or game readiness. Keep the catalog, release hashes and status honest; a source bundle is not a finished character. Do not broaden this project into game code.
