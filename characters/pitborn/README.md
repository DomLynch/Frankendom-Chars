# Pitborn · L2–L10

**Status:** L8 pilot in progress. L2–L10 are not yet delivered.

Pitborn is the existing Frankendom orc-blooded pit brute. The authoritative source character remains in `DomLynch/RPG-game`; this repository owns all new character-build work, evidence and delivery.

## Locked identity

- Preserve the existing Pitborn body proportions, skeleton, inverse binds, animation payload, hunch and cleaver placement.
- Preserve the shipped Pitborn scale/hunch contract: overall scale **1.13** with the existing spine/neck/head post-rotations from the game builder.
- Keep the cleaver as the weapon identity.
- Preserve L1 unchanged.
- Do not turn Pitborn into a generic plate knight or a differently proportioned monster.
